## What a Claude Plugin is

A **Claude Plugin** is a collection of **one or more skills** that take the
user's input and generate something **personalized and custom-made** for that
user — based on the user's own input and content, plus data or information
pulled from other sources.

Those other sources can include:

- a **knowledge base** or reference library bundled with the plugin,
- **websites** (live research, scraping, fetching),
- **databases**,
- **MCP connections** (e.g. Notion, Google Drive, Meta Ads, Circle),
- **API integrations**,
- **online research** (Google, YouTube, Reddit, forums, marketplaces),
- the user's uploaded files, links, and attachments.

The defining trait is **personalization**: the same plugin, run by two different
users, produces two genuinely different, custom-tailored outputs — because each
output is shaped by that user's specific input and situation.

## How a Claude Plugin works (the universal flow)

```
User provides the input or prompt
        │
        ▼
Plugin invokes the relevant skill(s)
   (gathers context: user input + knowledge base + websites +
    databases + MCP + APIs + online research)
        │
        ▼
Plugin generates a highly personalized output
        │
        ▼
Plugin delivers that custom-made output to the user
```

Said simply: **User input → skills run → personalized output delivered.**

Every skill in this plugin should design its work around this flow. When a skill
defines an idea, builds a plugin, writes copy, or makes an ad, the unit it is
operating on is *a plugin that turns user input into a personalized result.*

## How Claude Plugins are positioned in marketing & sales

In marketing and sales, a Claude Plugin is **not** sold as "software" or "a
tool." It is positioned as:

- **A Specialist / Expert on demand** — the plugin *is* the consultant,
  copywriter, coach, designer, strategist, or analyst, packaged so anyone can
  summon that expertise on demand.
- **A personalized done-for-you (DFY) service** — the output is highly
  personalized and custom-tailored for each user, exactly like hiring a
  professional to do the work *for* them — minus the cost, wait, and back-and-
  forth.

So the promise is never "a tool that helps you do X." It's **"your own [expert]
who creates a custom [deliverable] made just for you."**

| Don't position as | Position as |
|-------------------|-------------|
| "An AI fitness app" | "Your personal AI fitness coach who builds a plan around *your* body" |
| "A copywriting tool" | "Your on-demand sales copywriter who writes *your* page for *your* offer" |
| "An ad generator" | "Your AI ad specialist who designs scroll-stopping ads for *your* product" |
| "A roadmap template" | "Your AI strategist who maps the exact next steps for *your* business" |

## What makes a *great* AI product (the quality bar)

The best Claude Plugins share these traits — every skill should push toward them:

1. **Deep personalization.** The output is unmistakably *theirs* — it uses their
   inputs, their words, their context. A generic-feeling output is a failure.
2. **Done-for-you, not do-it-yourself.** The plugin makes the expert decisions a
   novice can't. The user gives raw input; the plugin returns a finished result.
3. **Specialist-grade output.** The deliverable looks like a professional made
   it — because the plugin encodes that professional's process.
4. **Fast time-to-value.** A usable, "wow" result quickly, from minimal input.
5. **A recurring, painful, or valuable job.** It targets something people
   currently do manually, dread doing, or pay specialists to do.
6. **Smart use of sources.** It enriches the user's input with knowledge bases,
   live research, MCP/API data, and databases — so the output is better than the
   user could produce alone.

## Glossary

- **AI Product** — a Claude Plugin (this plugin never means anything else by it).
- **Claude Plugin** — a collection of one or more skills that turn user input into
  a personalized, custom-made output.
- **Skill** — one capability inside a plugin; it gathers context and generates a
  deliverable.
- **Personalized / custom-made** — shaped by the individual user's input and
  context, so no two users get the same output.
- **Done-for-you (DFY)** — the plugin produces the finished deliverable *for* the
  user, rather than helping them make it themselves.
- **Specialist / Expert positioning** — selling the plugin as an on-demand expert
  who does the work, not as a tool the user has to operate.
